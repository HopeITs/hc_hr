## 2) رحلة الاستقبال (Onboarding)

خطوات تسير بالتوازي دون أن تنتظر إحداها الأخرى: سجل → عقد، ثم: حساب الدخول، الأجهزة، بطاقة الهوية، جلسة HR، جلسة المدير المباشر، الموافقة على السياسات، مراجعة دليل الإعلام.

- كل خطوة تُسجَّل بمن نفّذها، ونقرتان متتاليتان لا تغيّران شيئاً في الثانية.
- خطوة متأخرة: تذكير أسبوعي لصاحبها (الحساب، الأجهزة، البطاقة، جلسة المدير) عبر `SendOnboardingStepReminders` 08:12.
- جلسة توجيه متأخرة: تذكير واحد لـ HR المدينة 08:10.
- بعد بدء العقد: يُضاف المتطوع إلى القوائم البريدية التي تطابق قواعدها (بانتظار لوحة التحكم) 08:20.

### ملاحق العقد (مسودة → معتمد → مطبَّق)

- ملحق بتاريخ مستقبلي: يُطبَّق ليلاً 21:25.
- ملحق على عقد تغيّر بعد كتابته: يرفض التطبيق دون أن يكتب شيئاً.
- فك تشفير الأجر مستحيل: يرفض التطبيق.
- ملحق واحد مفتوح لكل عقد، وهو لـ HR فقط.
- تغيّر ساعات اليوم: تبقى أيام الإجازة المتبقية، وتُعاد تسعيرها بفارق `amendment_offset`.
- حذف ملحق مطبَّق (ولو بـ SQL): ممنوع؛ يكشفه فحص أسبوعي `contracts:amendments-check` (الأحد 06:00).
- التجديد بعد ملحق: يرث الشروط المعدّلة، وورقة العقد الموقّعة تعرض الشروط الأصلية.

### رحلة التجديد

تحذير الانتهاء ← قرار HR (تجديد/إيقاف) ← عقد لاحق ← أرصدة إجازة العقد الجديد. الإيقاف يمرّ بنفس طريق مفتاح الجدول، ولا يتكرر أثره.

## 6) التوظيف

### طلب التوظيف (Request)
الأنواع: ملء شاغر، زيادة عدد، تخفيض عدد، إنشاء وظيفة، إغلاق وظيفة، إغلاق شاغر. الأنماط: عادي أو مباشر HR.

الحالات: مسودة ← مقدَّم ← قيد المراجعة ← (تعديلات مطلوبة ← أُعيد تقديمه) ← معتمد / مرفوض / ملغى ← مُطبَّق / فشل التطبيق.

- تطبيق مؤرَّخ مستقبلاً: يُنفَّذ 00:30 قبل جولة العقود المسائية.
- تعديل حقول مقفلة بعد تقديم: يمنعه `RecruitmentFieldLock`.
- المعتمدون: يحدَّدون بالنطاق (محافظة، مدينة، برنامج)، وفي غياب HR المحافظة يوجد بديل.
- تأكيد خارجي (جهات خارج النظام) وسجل أحداث وتعليقات.
- طلب مالي من المالية نفسها: له اختبار خاص.

### حملة التوظيف
مسودة ← منشورة ← مفتوحة ← مغلقة / منتهية / معطّلة. `SyncRecruitmentCampaignStates` كل دقيقة؛ والوصول العام يعيد فحص الوقت في كل طلب.

### المتقدّم
مقدَّم ← قيد المراجعة ← قائمة مختصرة ← مقابلة محدّدة ← تمّت المقابلة ← نهائي ← مُختار ← عرض مرسل ← عرض مقبول/مرفوض ← **مُعيَّن**؛ مع انسحاب / رفض / أرشفة في أي مرحلة.

- تقديم عبر رابط عام: فحص مكافح فيروسات لكل ملف (حجر ثم فحص، وإعادة محاولة كل 15 دقيقة).
- متقدم مكرر: كاشف تكرار.
- مقابلة: مجدولة، أُعيدت جدولتها، ملغاة، مكتملة، لم يحضر. تذكيرات للمرشح كل 5 دقائق حسب الإزاحات.
- عرض وظيفي: مسودة ← مرسل ← مراجَع ← مقبول/مرفوض/منتهٍ/ملغى. العرض المتجاوز لتاريخ ردّه ينتهي (كل 15 دقيقة) دون المساس بالشاغر.
- رفض: رسالة تُعاد جدولتها إذا لم تصل الطابور.
- خصوصية: طلب محو وتصدير بيانات، والمحو التلقائي بالمدة مطفأ حتى `RECRUITMENT_RETENTION_ENFORCE`.
- **التعيين** يحوّل المرشّح إلى موظف + عقد + أرصدة + مقعد + رحلة استقبال (`HiringChainSimulationTest`).

## 7) المغادرة (Offboarding)

معدات مُعادة ← عقد منتهٍ ← تعطيل ← إغلاق الوصول والبطاقة (+ مقابلة خروج اختيارية). كل خطوة مقفلة ومشروطة بحالتها السابقة، فتكرارها لا يغيّر شيئاً.

## 9) الأخبار والسياسات والمجلس والملفات والتواصل

- **الأخبار**: كتابة ونشر وجمهور مستهدف ونشر خارجي ووسوم.
- **السياسات**: صفحات منسّقة، إصدارات، بحث، إقرار الموظف، فحص قراءة PDF.
- **المجلس**: ينشئ الاجتماع التالي في موعده، تذكير قبل يوم، متابعات، إعادة فتح، أقفال، رفع محاضر قديمة، وبطاقة لوحة التحكم.
- **المجلدات**: ملفات خاصة، مشاركة مع أفراد أو مجموعات، تصفّح مرفقات.
- **الدردشة** والمساعد والإشعارات (دفع، بريد، ملخص، ساعات هدوء، أيام عمل).
- **الشارات**: منح HR وعرضها في الملف.
- **مراجعة الأداء/التجربة**: طلب المدير (تمديد/تثبيت/إلغاء) إلى HR.
- **الاستبيانات والشكاوى**: موجودة كنماذج في `docs` (؟ لم أتحقق من أنها منفّذة).

## 10) الأمن والتشغيل

- كلمة مرور منسية، جلسة قائمة لمعطَّل، رؤوس أمان، تصاريح عبر المدن (`CrossCityPageSweepTest`، `RoleRouteSweepTest`).
- WebGuard قد يحجب `/iclock/*` فلا يدخل أي جهاز.
- `public/.htaccess` غير متتبَّع: لا يُكتب فوق قائمة IP المسموحة.
- مفتاح الرواتب بلا ضبط على الخادم يبدو كأنه يعمل: فحصه `salary:key:check`.
- PDF بحجم صفر: يشخّصه `contracts:export-doctor`.
- مقاعد خاطئة: `positions:recount` / `FixPositionEmployeeCounts`.
- سجل النشاط يُنقّى للحساس (`PurgeSensitiveActivityLog`)، وتيليمتري المحاولات 90 يوماً، والملاحظات سنة.

## 11) أماكن الأخطاء المحتملة (ما يُبنى عليه اختبار)

1. وظيفة بمقعدين يُنهي أحدهما عقده في ليلة تجديد الآخر: ترتيب 21:25 → 21:30 → 21:35 → 21:45 → 21:50 → 21:55 مهم، وهو مثبت باختبار.
2. إعادة تشغيل المساء مرتين: يجب ألا يتغيّر شيء ثانيةً.
3. ملحق وإنهاء في اليوم نفسه.
4. رصيد إجازة بعد تغيير ساعات اليوم ثم تجديد.
5. بصمات تصل بعد القفل أو بعد الاعتماد.
6. خلف في وظيفة بعدة شاغلين.
7. نسخة قاعدة بيانات على جهاز مطوّر دون مفتاح الرواتب.
8. جهاز بصمة غير مسجّل يعيد المحاولة بلا نهاية (يحتفظ بسجله).
